# app54【SMC】⑧チームタスク・予定管理

## 概要
メンバー（最大10人程度）のタスク・進捗管理と、休暇・研修・外出などの不在予定を1つのkintoneアプリで共有するためのアプリ。
スペース：渋谷マークシティ（https://325fggwl7tdq.cybozu.com/k/#/space/4）

## アプリ構成
- kintone標準の一覧表示は非表示にし、カスタマイズJSで独自UIを描画する構成。
- 1つのアプリ内で「種別」フィールド（ドロップダウン）によって3種類のレコードを使い分ける。
  - `メンバー` … メンバー登録用のダミーレコード（担当者名のみ保持）
  - `休暇` / `研修` / `外出` … 不在日の予定レコード
  - `タスク` … タスク管理レコード

## フィールド構成（主要なもの）
| フィールドコード | 型 | 用途 |
|---|---|---|
| 種別 | ドロップダウン | メンバー／休暇／研修／外出／タスク の区分 |
| 担当者 | 文字列（1行） | 自由記入（固定選択ではない） |
| 案件 | 文字列（1行） | タスクの案件名 |
| 詳細 | 文字列（1行） | タスクの詳細メモ |
| 日付 | 日付 | 予定の開始日／タスクの期限 |
| 終了日 | 日付 | 予定の終了日（同日の場合は開始日のみ表示） |
| 時間帯 | 文字列（1行） | 「時間帯・メモ」として自由記入 |
| 進捗状況 | 文字列（1行） | タスクの進捗（自由入力） |
| 優先度 | ドロップダウン | 高／中／低 |

## カスタマイズファイル
- `app54_team_task_leave.js` … デスクトップ版
- `app54_team_task_leave_mobile.js` … モバイル版（`kintone.mobile.app.getId()` を使用。デスクトップ版とは別ファイルで、メンバー登録セクションは非表示）

## 画面構成
1. **メンバー登録**（PC版のみ表示。モバイル版では非表示）
   - 登録済みメンバーをチップ表示、追加・削除が可能
   - 削除時、そのメンバーに未処理タスクが1件でもあれば削除をブロック（「タスクを完了または削除して、メンバー削除して下さい」と警告）
   - タスクが無ければ、そのメンバーの予定（休暇・研修・外出）も自動的に一緒に削除
2. **不在日（休暇・研修・外出）**
   - カード形式、開始日の昇順で自動整理
   - 終了日が本日より前の予定も削除はせず表示は残し、半透明表示にした上で自動的に「今日以降の最初の予定」の位置まで横スクロールし、期限切れ分は左の枠外に隠れる（左スクロールで確認可）
   - カードごとに編集（✎）・削除（✕）ボタンをカード右上に配置
   - 終了日が開始日より前の場合は入力エラーで保存させない
   - ヘッダー色：淡い青系＋左端アクセントバー
3. **タスク管理**
   - 担当者の絞り込みは横並びチップ（PC版はヘッダー直下、モバイル版もヘッダー内）。左サイドバー方式は廃止。
   - 列構成：優先度／案件／詳細／期限／進捗状況／操作（編集・削除）
   - 詳細欄は固定幅（PC版は360px＝当初比120%）、進捗状況欄は可変幅
   - 期限は「mm/ddまで」形式で表示
   - 列見出しは濃い黒文字・やや大きめサイズ、列間に薄いグレーの区切り線
   - タスク編集機能あり（担当者・案件・期限・詳細・優先度を変更可能。進捗状況欄は常時インライン編集）
   - 完了タスクの扱いは「進捗状況欄に完了等を入力して残す」か「削除」のどちらか（自動非表示機能は無し、という現状仕様で確定）
   - ヘッダー色：淡いティール系＋左端アクセントバー

## モバイル版の主な違い
- タスク一覧はグリッド表ではなく縦積みカード形式
- 左サイドバーの担当者レールを廃止し、上部の横スクロールチップに変更
- 不在日も縦積みカード形式
- メンバー登録セクションは非表示（メンバー名は既存の予定・タスクレコードから自動収集）
- 追加フォームの日付欄に「開始日」「終了日」「期限」のラベルを表示
- 画面下部までスクロールしてもkintone標準の一覧（`.gaia-mobile-v2-app-index-recordlist-table-wrapper`）が表示されないよう非表示化

## 開発中に判明した技術的なポイント
- kintoneの`preview/app/views.json`はPUTで**views全体を置き換える**ため、既存ビューを含めずに送ると消えてしまう（本アプリでは実害なし、他アプリ改修時の教訓として記録）
- モバイルページでは`kintone.app.getId()`が`null`を返す。モバイル用カスタマイズでは`kintone.mobile.app.getId()`を使う必要がある（デスクトップ用コードをそのまま流用すると動かない原因になった）
- レコード削除はAPIの**複数形エンドポイント**`/k/v1/records.json`をDELETEで呼ぶ必要がある。単数形`/k/v1/record.json`はDELETE非対応（`CB_HM01`エラー）
- カスタマイズJSファイルのアップロードはこの環境からは自動化できず、常にkintone管理画面から手動アップロードが必要
