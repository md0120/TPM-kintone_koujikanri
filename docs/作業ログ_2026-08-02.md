# 作業ログ 2026-08-02

## app54「【SMC】08_タスク管理」年間計画まわりの修正・機能追加

### バグ修正
- 年間計画の項目順（表示順フィールド＋▲▼ボタン）が効かない不具合を修正。原因は`表示順`が空欄の2レコードを入れ替えると両方とも`'0'`にフォールバックしてしまい実質何も変わらないバグ。一覧全体を毎回10,20,30…と振り直す方式に変更（メンバー登録側の▲▼も同様のバグを修正）
- 項目名欄の`<td>`に直接`display:flex`を指定していたため、ブラウザがそのセルを表セルとして扱わなくなり`rowspan`（複数行の結合）が効かなくなっていた不具合を修正。tdは通常のtable-cellのままにし、中身だけ内側の`<div>`でflexレイアウトするよう変更

### 機能追加：1項目に複数のガントバーを持てるように
- 案件名（項目名）が同じレコードをグループ化し、1項目内に複数のガントバー（レコード）をぶら下げられるよう再設計
- 項目名欄・▲▼欄は`rowSpan`でグループの行数ぶん結合表示
- 各項目の行に「＋」ボタンを追加し、押すとその項目に新しい線（レコード）が1本追加される
- 各線の右端に個別の「×」削除ボタンを配置（最後の1本を消すと項目自体が消える）
- 同一項目内の線と線の間の横罫線は非表示、項目と項目の間の罫線は維持

### UI微調整
- ▲▼ボタンを項目名欄の外（左側の専用の細い列）へ移動し、項目名欄を広く使えるように
- 項目名をクリックすると入力欄に切り替わり、その場で編集できるように（Enter/フォーカス外れで保存、Escapeでキャンセル）。複数行の項目は全レコードの案件名をまとめて更新
- ガントバーの色をグレー/緑/水/桃/橙から選べるように（app54に「バー色」ドロップダウンフィールドを追加）。バークリックで開く編集モーダルに丸いカラースイッチを追加
- ガントバーのテキストを「フォント11px・太さ普通・文字色黒・左揃え・はみ出し許可」に変更
- 項目名欄の文字サイズを段階的に調整（最終的に12.5px、`!important`漏れで一時反映されなかった問題も対応）
- 年間計画の年度送り（◀▶）機能を実装後、不要とのことで削除
